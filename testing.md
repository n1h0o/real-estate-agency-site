# Проверки

## Автоматические

- `npm run lint` — пройдено.
- `npm run build` — пройдено (TypeScript + production-сборка Vite).

## Ручные браузерные

- Отрисовка на настольной ширине и 390 px; горизонтального переполнения при 390 px нет.
- Видны каталог, фильтры, карточки, форма и диалог; изображения загрузились после прокрутки страницы.
- Фильтр типа недвижимости и счётчик избранного проверены через интерфейс.
- Полный повтор фильтра избранного и сброса нужно повторить на свежем состоянии; результаты переходов CUA при серии кликов не всегда были последовательны.

## Границы проверки

- Серверной доставки формы нет и не заявляется.
- Визуально проверено только локальное окружение; перед клиентским запуском проверить в поддерживаемых браузерах и целевой инфраструктуре.
