# Форма — бюро пространства

Готовый демонстрационный сайт-каталог недвижимости для агентства на русскоязычном рынке СНГ. Включает адаптивную витрину, фильтры, сортировку, избранное, карточки с подробностями и форму запроса.

Объекты, цены и районы — примеры наполнения, а не реальные предложения. Форма работает локально и не передаёт данные.

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run lint
npm run build
```
