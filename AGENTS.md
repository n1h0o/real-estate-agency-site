# Инструкции проекта

- Сохраняй уникальную визуальную идентичность «Форма»: минеральная база, графитово-синий, Manrope + локальный редакционный акцент Playfair.
- Не называй демонстрационные районы, цены, контакты или карточки реальными предложениями. При адаптации меняй контент на проверенные данные владельца.
- Без отдельной интеграции форма только локально подтверждает данные и ничего не отправляет.
- Не добавляй ненужные зависимости и не переиспользуй шаблон соседних сайтов.
- Проверяй мобильный вид, клавиатуру, видимый фокус и `prefers-reduced-motion`.
- Не удаляй репозитории, историю или данные; не деплой без отдельного подтверждения владельца.
