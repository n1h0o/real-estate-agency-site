# Готовность демонстрационного продукта

- [x] Адаптивный каталог, фильтры, сортировка, избранное, детали объекта.
- [x] Форма с браузерной валидацией и ясным локальным подтверждением.
- [x] Демонстрационные сведения явно помечены; реальные контакты и интеграции не выдуманы.
- [x] Система учитывает клавиатуру и уменьшение анимации.
- [ ] Перед внедрением заполнить проверенные предложения и данные конкретного агентства.
- [ ] Для реального сбора обращений подключить адресата, обработчик, согласованный текст обработки данных и требования юрисдикции.
- [ ] Публикация или деплой — только после отдельного подтверждения владельца.
