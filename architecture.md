# Архитектура

Статическое одностраничное React-приложение на TypeScript и Vite. Каталог — локальный типизированный массив примеров; `useMemo` применяет фильтры, сортировку и избранное на клиенте. Состояния фильтров, избранного, модального окна и локального подтверждения формы живут в компоненте `App`. API и база данных для демонстрационного продукта не требуются.
